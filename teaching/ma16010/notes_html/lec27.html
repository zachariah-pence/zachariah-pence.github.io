Lecture 27: Introduction to Differential Equations and IVPs

Goal: Be able to solve (very basic) differential equations by integration.

Definition. For \( y = f(x) \), a differential equation is an equation involving \( x \), \( y \), and the derivatives of \( y \).

Here are some examples (\( m \) and \( k \) are constants):

Examples of differential equations and their English translations
Equation English Translation
\( \dfrac{d^2y}{dx^2} = -9.81 \) “Acceleration due to gravity is constant.”
\( \dfrac{dy}{dx} = ky \) “The rate a population grows is proportional to the amount of organisms in the population.”
\( \dfrac{d[y]}{dt} = -k[x_{(t)}][y_{(t)}] \) “The speed of a chemical reaction is proportional to the number of interactions between the molecules.”
\( m\dfrac{d^2y}{dx^2} + k\sin y = 0 \) “The net force acting on an oscillating pendulum is 0.”

Example 1.

Verify \( y = 3e^{2x} \) is a solution to the differential equation \( y' = 2y \).

\[ \begin{gathered} LHS: y' = \left[3e^{2x}\right]' = 2 \cdot 3 e^{2x} = 6e^{2x} \\[0.5em] RHS: 2y = 2\left[3e^{2x}\right] = 6e^{2x} \end{gathered} \]

So indeed \( y' = 2y \).

Example 2.

Solve the differential equation \( y' = \dfrac{1}{x} \).

\[ \begin{gathered} y'_{(x)} = \frac{1}{x} \\[0.5em] \int y'_{(x)}\, dx = \int \frac{1}{x}\, dx \\[0.5em] y_{(x)} = \ln|x| + C \end{gathered} \]

Definition. The general solution to a differential equation is a function that describes all possible solutions of the differential equation.

Example 3.

Find the general solution to \( y' = 3x^2 \)

\[ \begin{gathered} y' = 3x^2 \\[0.5em] \int y'\, dx = \int 3x^2\, dx \\[0.5em] y = 3 \cdot \frac{x^{2+1}}{2+1} + C \\[0.5em] y = x^3 + C \end{gathered} \]

The general solution gives us a whole family of solutions to our differential equation.

Question: Is there a way to have a unique (i.e., only 1) solution?

Answer:

Ask that \( y \) also passes through a point (e.g., \( y(0) = 0 \), so our solution must also pass through the origin).

Definition. The extra condition above is an example of an initial condition. Usually, we specify when \( x = 0 \) (but that is not required).

IVPs

Definition. An initial value problem (IVP) is a differential equation combined with initial conditions.

Example 4.

The system

\[ \begin{cases} y' = \sqrt{x} \\ y(0) = 1 \end{cases} \]

is an IVP. How can we solve it?

Step 1: Find the general solution

\[ \begin{gathered} y' = \sqrt{x} \\[0.5em] \int y'\, dx = \int \sqrt{x}\, dx \\[0.5em] y_{(x)} = \int x^{\frac{1}{2}}\, dx \\[0.5em] y_{(x)} = \frac{x^{\frac{1}{2}+1}}{\frac{1}{2}+1} + C \\[0.5em] y_{(x)} = \frac{2}{3} x^{\frac{3}{2}} + C \end{gathered} \]

Step 2: Solve for \( C \) using the initial condition

\[ \begin{gathered} 1 \overset{\text{should}}{=} y_{(0)} = \frac{2}{3}(0)^{\frac{3}{2}} + C \\[0.5em] 1 = 0 + C \\[0.5em] C = 1 \end{gathered} \]

Therefore, the solution to the IVP is

\[ y_{(x)} = \frac{2}{3} x^{\frac{3}{2}} + 1 \]

Definition. We say \( y \) is (directly) proportional to \( x \) if there is a constant \( k \) such that \( y = kx \).

Example 5.

The size of a population is governed by

\[ \frac{dP}{dt} = \sqrt[3]{t} \]

where \( P \) is the population after \( t \) days (i.e., \( \frac{dP}{dt} \) is proportional to \( \sqrt[3]{t} \) with constant coefficient of 1). If the initial population is 1000, find the population size after 8 days.

We need to find \( P(8) \), where \( P \) is a Solution to the IVP

\[ \begin{cases} \frac{dP}{dt} = t^{\frac{1}{3}} \\ P(0) = 1000 \end{cases} \]

Solving for the general solution we get

\[ \begin{gathered} \frac{dP}{dt} = t^{\frac{1}{3}} \\[0.5em] \int \frac{dP}{dt}\, dt = \int t^{\frac{1}{3}}\, dt \\[0.5em] P_{(t)} = \frac{t^{\frac{1}{3}+1}}{\frac{1}{3}+1} + C \\[0.5em] P(t) = \frac{3}{4} t^{\frac{4}{3}} + C \end{gathered} \]

Incorporate the initial condition:

\[ \begin{gathered} 1000 \overset{\text{should}}{=} P(0) = \frac{3}{4} \cdot 0^{\frac{4}{3}} + C = C \\[0.5em] P(t) = \frac{3}{4} t^{\frac{4}{3}} + 1000 \end{gathered} \]

Thus, after 8 days, the population size is

\[ P(8) = \frac{3}{4} \cdot 8^{\frac{4}{3}} + 1000 = \frac{3}{4} \left( \sqrt[3]{8} \right)^{4} + 1000 = 12 + 1000 = 1012 \]

Multiple ICs

Fact: The have a unique solution, you need \( N \) ICs where \( N \) is the highest order of the derivatives in the differential equation.

Example 6. Solve the IVP:

\[ \begin{cases} y''(t) = t - 3 \\ y'(1) = \frac{1}{2} \\ y(0) = 1 \end{cases} \]

Ie, we need to integrate twice and incorporate the initial conditions along the way

\[ \begin{gathered} y''(t) = t - 3 \\[0.5em] \int y''(t)\, dt = \int (t-3)\, dt \\[0.5em] y'(t) = \frac{1}{2} t^2 - 3t + C \end{gathered} \]

We know \( y'(1) = \frac{1}{2} \). So

\[ \begin{gathered} \frac{1}{2} \overset{\text{should}}{=} y'(1) = \frac{1}{2} - 3 + C \\[0.5em] \frac{1}{2} = \frac{1}{2} - 3 + C \\[0.5em] C = 3 \\[0.5em] \Longrightarrow \quad y'(t) = \frac{1}{2} t^2 - 3t + 3 \end{gathered} \]

Then repeat to get \( y(t) \):

\[ \begin{gathered} \int y'(t)\, dt = \int \left( \frac{1}{2} t^2 - 3t + 3 \right) dt \\[0.5em] y(t) = \frac{1}{6} t^3 - \frac{3}{2} t^2 + 3t + D \end{gathered} \]

We know \( y(0) = 1 \), so:

\[ 1 \overset{\text{should}}{=} y(0) = 0 - 0 + 0 + D = D \]

Therefore, the solution to the IVP is

\[ y(t) = \frac{1}{6} t^3 - \frac{3}{2} t^2 + 3t + 1 \]

NOTE:

You can always check your work by differentiating.

\[ \begin{gathered} y(t) = \frac{1}{6} t^3 - \frac{3}{2} t^2 + 3t + 1 \\[0.5em] y(0) = 0 - 0 + 0 + 1 = 1 \\[0.5em] y'(t) = \frac{1}{2} t^2 - 3t + 3 \\[0.5em] y'(1) = \frac{1}{2} - 3 + 3 = \frac{1}{2} \\[0.5em] y''(t) = t - 3 \end{gathered} \]

So \( y(t) \) satisfies all 3 conditions.

Example 7.

A ball is kicked off the ground with an initial velocity of 20 \( \text{m/s} \). Describe the height of the ball as a function of time (assume gravity is the only force acting on the ball once it is kicked).

We Solve the IVP

\[ \begin{cases} a(t) = s''(t) = -9.81 \\ v(0) = s'(t) = 20 \\ s(0) = 0 \end{cases} \] \[ \begin{gathered} a(t) = -9.81 \\[0.5em] \int a(t)\, dt = \int -9.81\, dt \\[0.5em] v(t) = -9.81t + C \end{gathered} \]

Since \( v(0) = 20 \):

\[ \begin{gathered} 20 \overset{\text{should}}{=} v(0) = 0 + C = C \\[0.5em] v(t) = -9.81t + 20 \end{gathered} \]

Integrating again we get:

\[ \begin{gathered} \int v(t)\, dt = \int (-9.81t + 20)\, dt \\[0.5em] s(t) = -4.905t^2 + 20t + D \end{gathered} \]

Since \( s(0) = 0 \):

\[ 0 \overset{\text{should}}{=} s(0) = 0 + 0 + D \]

Therefore

\[ s(t) = -4.905t^2 + 20t \]

Example 8 (HW 27, Q6). Solve the IVP:

\[ \begin{gathered} \begin{cases} y''(x) = 4\sin x + \frac{10}{\pi^2} x \\ y'(\pi) = 4 \\ y\left(\frac{\pi}{2}\right) = -4 \end{cases} \\[0.5em] y''(x) = 4\sin x + \frac{10}{\pi^2} x \\[0.5em] \int y''(x)\, dx = \int \left( 4\sin x + \frac{10}{\pi^2} x \right) dx \\[0.5em] y'(x) = -4\cos x + \frac{5}{\pi^2} x^2 + C \end{gathered} \]

Since \( y'(\pi) = 4 \):

\[ \begin{gathered} 4 \overset{\text{should}}{=} y'(\pi) = -4\cos \pi + \frac{5}{\pi^2} (\pi)^2 + C \\[0.5em] 4 = 4 + 5 + C \\[0.5em] C = -5 \\[0.5em] \Longrightarrow \quad y'(x) = -4\cos x + \frac{5}{\pi^2} x^2 - 5 \end{gathered} \]

Do it again:

\[ \begin{gathered} \int y'(x)\, dx = \int \left( -4\cos x + \frac{5}{\pi^2} x^2 - 5 \right) dx \\[0.5em] y(x) = -4\sin x + \frac{5}{3\pi^2} x^3 - 5x + D \end{gathered} \]

Since \( y\left(\frac{\pi}{2}\right) = -4 \):

\[ \begin{gathered} -4 \overset{\text{should}}{=} y\left(\frac{\pi}{2}\right) = -4(1) + \frac{5}{3\pi^2} \left(\frac{\pi}{2}\right)^3 - 5 \cdot \frac{\pi}{2} + D \\[0.5em] -4 = -4 + \frac{5\pi}{24} - \frac{5\pi}{2} + D \\[0.5em] D = \frac{5\pi}{2} - \frac{5\pi}{24} \\[0.5em] D = \frac{55\pi}{24} \end{gathered} \]

Therefore, the solution is

\[ y(x) = -4\sin x + \frac{5}{3\pi^2} x^3 - 5x + \frac{55\pi}{24} \]
