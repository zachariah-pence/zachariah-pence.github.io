Antiderivatives

Definition. A function \( F \) is an antiderivative of \( f \) on an interval \( I \) if \( F'(x) = f(x) \) for all \( x \) an \( I \). (If \( I \) is not specified, then it is just the domain of \( f \)).

Example 1.

Consider the function \( f(x) = x \):

  1. Is \( F(x) = \frac{1}{2} x^2 \) an antiderivative of \( x \) (on \( I = (-\infty, \infty) \))?

    \[ F'(x) = \frac{1}{2} \cdot 2x = x \quad \checkmark \quad \text{Yes} \]

  2. Is \( F(x) = x^2 \) an antidervative of \( x \)?

    \[ F'(x) = 2x \ne x \quad \text{No} \]

  3. Is \( F(x) = \frac{1}{2} x^2 + 1 \) an antiderivative of \( x \)?

    \[ F'(x) = \frac{1}{2} \cdot 2x + 0 = x \quad \checkmark \quad \text{Yes} \]

Conclusion: Antiderivatives are not unique. We have any function of the form \( \frac{1}{2} x^2 + [\text{a constant}] \) is an antiderivative, but are there any others?

Theorem. If \( F' = 0 \) on an interval, then \( F \) is constant on the interval.

NOTE (WHY?)

Formally, we need to use the Mean Value Theorem (I'll add an article in the non-examinable section...eventually). That being said, it makes sense if we treat \( F' \) like velocity; if your velocity is 0 you're not moving, so your position is constant.

Corollary. Corollary If \( F \) and \( G \) are antiderivatives of a function \( f \), then

\[ F(x) = G(x) + C \]

for some constant \( C \).

NOTE (WHY?)

This is a computation

\[ [F(x) - G(x)]' = F'(x) - G'(x) = f(x) - f(x) = 0 \]

So \( F(x) - G(x) \) is a constant by the previous Theorem.

So to answer the question, no, those were the only possible antiderivatives of \(\frac{1}{2}x^2\).

Indefinite Integration

Definition. The family of antiderivatives of a function \( f \) is called the (indefinite) integral of \( f \), denoted

\[ \int f(x)\, dx \xlongequal{\text{BY THE COROLLARY}} F(x) + C \]

Let's take a moment to introduce some vocabulary:

  1. The symbol \(\displaystyle\int\) is called the integral sign;
  2. The function inside the integral (in this case \(f(x)\)) is called the integrand;
  3. \(x\) is called the integration variable;
  4. The function \(F(x)\) as above is a particular antiderivative of \(f(x)\);
  5. The constant \(C\) is called the constant of integration.

Example 2.

Find all possible antiderivatives of \( f(x) = \sin x \).

Step 1: Find a particular antiderivative

\[ \begin{gathered} [\cos x]' = -\sin x \\[0.5em] (-1)[\cos x]' = \sin x \\[0.5em] [-\cos x]' = \sin x \end{gathered} \]

Step 2: Compute the integral

\[ \int \sin x\, dx = -\cos x + C \]

Example 3.

Compute \( \int \frac{1}{x}\, dx \) on \( (0, \infty) \)

Step 1:

\[ [\ln x]' = \frac{1}{x} \]

Step 2:

\[ \int \frac{1}{x}\, dx = \ln x + C \]

Theorem. In general, on \( (-\infty, 0) \cup (0, \infty) = \left\{ \text{domain of } \frac{1}{x} \right\} \)

\[ \int \frac{1}{x}\, dx = \ln |x| + C \]

Example 4.

Compute \( \int x^2\, dx \)

Step 1:

\[ \begin{gathered} [x^3]' = 3x^2 \\[0.5em] \frac{1}{3}[x^3]' = x^2 \\[0.5em] \left[\frac{1}{3}x^3\right]' = x^2 \end{gathered} \]

Step 2:

\[ \int x^2\, dx = \frac{1}{3}x^3 + C \]

Theorem (Reverse Power Rule). When \( n \ne -1 \)

\[ \int x^n dx = \frac{x^{n+1}}{n+1} + C = \frac{1}{n+1}x^{n+1} + C \]

Example 5.

\[ \begin{gathered} \int \sqrt{x}\, dx = \int x^{\frac{1}{2}}\, dx = \frac{x^{\frac{1}{2}+1}}{\frac{1}{2}+1} + C = \frac{x^{\frac{3}{2}}}{\frac{3}{2}} + C \\[0.5em] = \frac{2}{3}x^{\frac{3}{2}} + C \end{gathered} \]

Theorem. Integrals are linear in the sense that:

(i) \( \int (f(x) \pm g(x))\, dx = \int f(x)\, dx \pm \int g(x)\, dx \)

(ii) If \( k \) is a constant, \( \int k f(x)\, dx = k \int f(x)\, dx \)

Example 6.

Compute \( \int \frac{2x^5 - \sqrt{x}}{x}\, dx \)

\[ \begin{gathered} \int \frac{2x^5 - \sqrt{x}}{x}\, dx = \int \left( \frac{2x^5}{x} - \frac{\sqrt{x}}{x} \right) dx \\[0.5em] = \int \left( \frac{2x^5}{x} - \frac{x^{\frac{1}{2}}}{x} \right) \\[0.5em] = \int \left( 2x^4 - x^{-\frac{1}{2}} \right) dx \\[0.5em] = 2 \int x^4\, dx - \int x^{-\frac{1}{2}}\, dx \\[0.5em] = 2 \cdot \frac{x^{4+1}}{4+1} - \frac{x^{-\frac{1}{2}+1}}{-\frac{1}{2}+1} + C \\[0.5em] = \frac{2}{5}x^5 - \frac{x^{\frac{1}{2}}}{\frac{1}{2}} + C \\[0.5em] = \frac{2}{5}x^5 - 2\sqrt{x} + C \end{gathered} \]

Remark 1 (Notation): Add parentheses when the integrand has more than one term:

\[ \begin{gathered} \int x^2 + x^3\, dx \longleftarrow \text{Not Quite Right} \\[0.5em] \int (x^2 + x^3)\, dx \longleftarrow \text{Correct} \end{gathered} \]

Remark 2: When dealing with multiple integrals, it is common practice to have only one constant of integration and to tack it on at the very end. We will demonstrate why in the next example.

Example 7.

Compute \( \int \sec x(\sec x + \cos x)\, dx \)

\[ \begin{gathered} \int \sec x(\sec x + \cos x)\, dx = \int (\sec^2 x + \sec x \cos x)\, dx \\[0.5em] = \int (\sec^2 x + 1)\, dx \\[0.5em] = \int \sec^2 x\, dx + \int 1 \cdot x^0\, dx \\[0.5em] = \tan x + C_1 + x + C_2 \\[0.5em] = \tan x + x + \left[ C_1 + C_2 \right] \\[0.5em] = \tan x + x + C \end{gathered} \]

Adding two arbitrary constants gets us another arbitrary constant, so let \( C = C_1 + C_2 \)

Example 8.

Compute \( \int \frac{14 + 4xe^x}{x}\, dx \)

\[ \begin{gathered} \int \frac{14 + 4x e^x}{x}\, dx = \int \left( \frac{14}{x} + \frac{4xe^x}{x} \right) dx \\[0.5em] = \int \left( \frac{14}{x} + 4e^x \right) dx \\[0.5em] = 14 \int \frac{1}{x}\, dx + 4 \int e^x\, dx \\[0.5em] = 14 \ln |x| + 4 e^x + C \end{gathered} \]

A Glimpse into MA 16020

We want techniques to "undo" the use of the Product, Quotient, and Chain Rule. You won't need this for 16010, but here is an example of such a thing:

Theorem (Reverse Chain Rule/"U-substitution"). If \( F \) is an antiderivative for \( f \). Then,

\[ \int f(g(x)) \cdot g'(x)\, dx = F(g(x)) + C \]

Example 9.

Compute \( \int \cos(2x)\, dx \)

We would love to say \( \sin(2x) \) is an antiderivative, but that's false:

\[ \left[ \sin(2x) \right]' = \cos(2x) \cdot 2 \]

So to integrate this, we need the derivative of the inside function (in this example \( 2x \)) in our integral; Ie, we need a \( 2 \). We can get it through some algebra

\[ \begin{gathered} \int \cos(2x)\, dx = \frac{2}{2} \int \cos(2x)\, dx \\[0.5em] = \frac{1}{2} \int \underbrace{\cos(2x)}_{f(g(x))} \cdot \underbrace{2}_{g'(x)}\, dx \\[0.5em] = \frac{1}{2} \sin(2x) + C \end{gathered} \]
