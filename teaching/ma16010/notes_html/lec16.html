Lecture 16: Relative Extrema and Critical Numbers

Goal: Discuss when a function's behavior changes.

Consider the following graph:

Def A fun \( f \) has a relative maximum (or local max) at \( x=c \) if there is an interval \( I \) containing \( c \) such that \( f(x) \le f(c) \) for \( x \) in \( I \).

Def A relative minimum (or local min) is obtained by replacing "\( f(x) \le f(c) \)" with "\( f(c) \le f(x) \)" is the prior def.

Theorem (Fermat, \( \sim 1636 \)) If \( f \) has a rel. max or min at a \( c \), then \( f'(c) \) is either \( 0 \) or undefined.

NOTE:

The reverse is not true

Def Let \( c \) be in the domain of \( f \). If \( f'(c) \) is \( 0 \) or undefined, we say \( c \) is a critical number (or critical point or critical value) of \( f \).

Example 1

Let \( f(x) = 2\cos(5x) + 5x \)

  1. Is \( x = \frac{\pi}{30} \) a critical number for \( f \)?

    \[ \begin{gathered} f'(x) = -10\sin(5x) + 5 \\[0.5em] f'\left(\frac{\pi}{30}\right) = -10\sin\left(5 \cdot \frac{\pi}{30}\right) + 5 = -10\sin\left(\frac{\pi}{6}\right) + 5 \\[0.5em] = -10\left(\frac{1}{2}\right) + 5 = 0 \ \checkmark \ \text{yes} \end{gathered} \]

  2. Is \( x = \pi \) a crit. num. for \( f \)?

    \[ \begin{gathered} f'(x) = -10\sin(5x) + 5 \\[0.5em] f'(\pi) = -10\sin(5\pi) + 5 \\[0.5em] = 5 \ne 0 \quad \text{or undefined} \end{gathered} \]

    X; it is a crit. num.

Example 2

Find all critical numbers for

\[ \begin{gathered} f(x) = x^3 - 75x \\[0.5em] f'(x) = 3x^2 - 75 \end{gathered} \]

\( f' \) is never undefined. So, we need to solve

\[ \begin{gathered} 3x^2 - 75 \overset{\text{set}}{=} 0 \\[0.5em] 3(x^2 - 25) = 0 \\[0.5em] 3(x-5)(x+5) = 0 \\[0.5em] \Rightarrow x = -5, 5 \end{gathered} \]

Example 3

Find all critical numbers for

\[ \begin{gathered} f(x) = x^3 + 5x^2 + 7x \\[0.5em] f'(x) = 3x^2 + 10x + 7 \end{gathered} \]

\( f' \) is never undefined. So, we do the following

\[ \begin{gathered} \underset{a}{3}x^2 + \underset{b}{10}x + \underset{c}{7} \overset{\text{set}}{=} 0 \\[0.5em] ax^2 + bx + c = 0 \Rightarrow x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \\[0.5em] x = \frac{-10 \pm \sqrt{(10)^2 - 4(3)(7)}}{2(3)} = \frac{-10 \pm \sqrt{100 - 84}}{6} \\[0.5em] = \frac{-10 \pm \sqrt{16}}{6} = \frac{-10 \pm 4}{6} \Rightarrow x = \frac{-10 + 4}{6}, \ x = \frac{-10 - 4}{6} \\[0.5em] \Rightarrow x = -1, -\frac{7}{3} \end{gathered} \]

Example 4

Find all critical numbers of

\[ \begin{gathered} f(x) = 4x^3 - \frac{4}{x^3} \\[0.5em] f'(x) = 12x^2 - \left[4x^{-3}\right]' = 12x^2 + 12x^{-4} \\[0.5em] = 12x^2 + \frac{12}{x^4} \end{gathered} \]

NOTE:

It is tempting to say \( 0 \) is a critical number here since \( f'(0) \) is undefined. But remember, critical numbers are in the domain of the function, which \( 0 \) is not.

\( f' \) is never undefined (in the domain of \( f \)).

So, we solve \( f'(x) = 0 \)

\[ \begin{gathered} 12x^2 + \frac{12}{x^4} \overset{\text{set}}{=} 0 \\[0.5em] x^4\left(12x^2 + \frac{12}{x^4}\right) = 0 \cdot x^4 \\[0.5em] 12x^6 + 12 = 0 \\[0.5em] x^6 + 1 = 0 \end{gathered} \]

NO Real Solution

\( \Rightarrow f \) has no critical numbers.

Example 5

Repeat for

\[ \begin{gathered} f(x) = xe^x \\[0.5em] f'(x) = (1)e^x + xe^x \end{gathered} \]

\( f' \) is never undefined. So, we solve

\[ \begin{gathered} 1 \cdot e^x + xe^x \overset{\text{set}}{=} 0 \\[0.5em] e^x(1+x) = 0 \\[0.5em] e^x = 0 \quad \textbf{OR} \quad 1+x = 0 \end{gathered} \]

Never

\[ \boxed{x = -1} \]

Example 6

Repeat for

\[ \begin{gathered} f(x) = 6x^4 e^{5x+4} \\[0.5em] f'(x) = 24x^3 e^{5x+4} + 6x^4\left[5 \cdot e^{5x+4}\right] \\[0.5em] = 24x^3 e^{5x+4} + 30x^4 e^{5x+4} \overset{\text{set}}{=} 0 \\[0.5em] 6x^3 e^{5x+4}\left[4 + 5x\right] = 0 \\[0.5em] 6x^3 = 0 \quad \textbf{OR} \quad e^{5x+4} = 0 \quad \textbf{OR} \quad 4 + 5x = 0 \\[0.5em] \boxed{x = 0} \end{gathered} \]

Never

\[ \boxed{x = -\frac{4}{5}} \]

Ex 7

Repeat for \( f(x) = \frac{\ln x}{x} \)

\[ f'(x) = \frac{\frac{1}{x} \cdot x - (1)\ln x}{x^2} = \frac{1 - \ln x}{x^2} \]

\( f'(x) \) is never undefined (in the domain of \( f \))

\[ \begin{gathered} \frac{1 - \ln x}{x^2} = 0 \\[0.5em] 1 - \ln x = 0 \\[0.5em] \ln x = 1 \\[0.5em] \boxed{x = e} \end{gathered} \]
